# About Me

I am a DevOps engineer who moved into the field from a civil engineering background. Over the past year I have taught myself the core of modern delivery work and put it into practice on real projects, building the path from a code commit to a running, verified deployment.

What I enjoy most is the operational side: containerizing applications, wiring up CI/CD pipelines, and troubleshooting the messy, real-world failures that only show up once something is actually running. A lot of what I know came from things breaking and figuring out why, which is why this site includes a [Troubleshooting](troubleshooting.md) page as well as project write-ups.

**What I work with hands-on:**

- Docker and Docker Compose for containerization and local orchestration
- Kubernetes at the manifest level, running workloads locally on minikube and kind
- CI/CD automation with Jenkins and GitHub Actions
- Container health checks, health-gated startup, and restart-based self-healing
- Cloud deployment (Google Cloud Run, DigitalOcean) and Linux servers
- Secrets and environment configuration
- Git workflows: branching, pull requests, rebasing, and conflict resolution
- AI-native development with Cursor and Claude Code

I am currently preparing to sit the **KCNA (Kubernetes and Cloud Native Associate)** exam, and I am focused on junior and entry-level DevOps and platform roles where I can turn this project work into production impact.
