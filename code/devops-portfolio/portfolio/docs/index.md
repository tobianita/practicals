## Overview

I am a DevOps engineer who enjoys building reliable systems and automating the journey from code to production. What I like most is containerizing applications, setting up CI/CD pipelines, and troubleshooting real deployment issues to keep systems healthy.

I work hands-on with Docker, Kubernetes (writing manifests and running workloads locally on minikube/kind), CI/CD automation with Jenkins and GitHub Actions, container health monitoring, secrets and environment configuration, cloud deployment, and collaborating through shared Git repositories. I build AI-natively, using Cursor and Claude Code day to day.

I moved into DevOps from a civil engineering background, and I am currently preparing to sit the KCNA (Kubernetes and Cloud Native Associate) exam.
